分水器类报价逻辑

主管、支管、支路配件和通用成本组合计算

1. 通用取值

  • 管材成本按实际壁厚、外径、长度计算重量，再按管材材料单价去税计入成本。
  • 配件价格表维护的是含税价；304 配件 = 含税表价 ÷ 配件含税系数，316L 配件 = 含税表价 x 316L配件系数 ÷ 配件含税系数。
  • 配件理论重量 = 配件去税成本 / (((钢价 + 2000) / 1000) x 配件重量系数)。
  • 含税工厂成本 = 不含税成本小计 x 成本含税系数；面价折后 = 含税工厂成本 / 成本率；单价面价 = 面价折后 / 面价折扣。

2. 分水器组成

  • 分水器由主管、支管、进水端配件、末尾配件和各支路配件组成，支路数量支持 1-20 口。
  • 主管长度 = 进水尺寸 L + 各支路间距 P 累计 + 末尾尺寸 E。
  • 支管不加高时不计支管管材；支管加高时按加高长度计算支管重量和材料费。
  • 国标大规格默认壁厚：D133 = 2.5，D159 = 2.5，D219 = 3.0。

3. 加工与后处理

  • 1口产品也按 2口基础加工费起算。
  • 分水器加工费 = (2口基础 + 增加支路 + 加高支路) x 规格系数 + 大规格开孔费，再乘难度系数。
  • 主管外径 D133/D159/D219 时，每个支路孔额外增加 15 元开孔费。
  • 退火、制造管理、包材、表面处理按管材总重量计算；法兰只计配件成本，不进入退火、制造管理和包材重量。

分水器不含税成本 = 主管材料 + 支管材料 + 配件 + 分水器加工费 + 退火 + 制造管理 + 包材 + 表面处理。

对接类报价逻辑

A端、B端和中间段分开计算

1. 组成与长度

  • A/B 两端可分别选择外径、壁厚和连接方式；无配件时不显示标识、不计配件。
  • 对接默认无中间段；启用后中间段可为直管或中接。
  • 中间段为直管时按直管长度计算管材重量；中间段为中接时按中接配件计成本和理论重量。
  • A/B 外径不一致时可自动启用中接，但用户选择后不锁死。

2. 加工与重量

  • 对接加工费使用独立对接类加工费表，按配件类型 x 外径取值。
  • 加工费 = A端加工 + B端加工 + 中接加工，再乘成型加工系数和难度系数。
  • 退火/包材重量 = 中间直管重量 + A/B端非法兰配件理论重量 + 中接理论重量。
  • 不带法兰：制造管理 = 加工费 x 2.14；带法兰：制造管理 = 扣除法兰后的产品重量 x 4.13。
  • 表面处理只按中间直管材料重量计算，不按配件理论重量计算。

对接不含税成本 = 中间直管材料 + A/B端配件 + 中接配件 + 对接加工费 + 退火 + 制造管理 + 包材 + 表面处理。

三通类报价逻辑

三通体、A/B/C 三端和中间段组合计算

1. 组成与尺寸

  • 三通体由外径、壁厚、三通体直管长度决定，直管长度可从尺寸表带出，也可手输。
  • 三通体选择外径时，一般联动 A/B/C 三端规格。
  • A/C端中间段支持无或中接；B端中间段支持无或直管。
  • B端选择法兰时，默认启用 B端直管，长度带入 50 mm，可手动修改。
  • D133/D159/D219 可使用沟槽、对焊、法兰。

2. 加工与重量

  • 三通加工费使用独立三通类加工费表，按配件类型 x 外径取值。
  • 加工费 = A端加工 + B端加工 + C端加工 + 中接加工，再乘成型加工系数和难度系数。
  • 退火/包材重量 = 三通体直管重量 + B端直管重量 + A/B/C端非法兰配件理论重量 + A/C中接理论重量。
  • 不带法兰：制造管理 = 加工费 x 2.14；带法兰：制造管理 = 扣除法兰后的产品重量 x 4.13。
  • 表面处理只按三通体直管和 B端直管等实际管材重量计算。

三通不含税成本 = 三通体/直管材料 + A/B/C端配件 + 中接配件 + 三通加工费 + 退火 + 制造管理 + 包材 + 表面处理。

弯头类报价逻辑

弯头体价格、中心高度和 A/B 端组合计算

1. 组成与弯头本体

  • 弯头由弯头本体、A端配件、B端配件和 A/B端中间段组成，角度支持 45° 和 90°。
  • 弯头本体价格使用配件价格表中的 45弯头或 90弯头行，按含税表价去税后计入成本。
  • 弯头材料重量按中心高度 H x 2.5 的料长折算，用于退火、包材和表面处理，不直接决定弯头本体价格。
  • 45°弯头加工角度系数为 0.8，90°为 1。

2. A/B端与加工

  • A/B端中间段支持无、直管、中接；直管按输入长度计管材，中接按配件计成本。
  • 弯头加工费使用独立弯头类加工费表，按配件类型 x 外径取值。
  • 加工费 = A/B端加工 + 中接加工，再乘角度系数、成型加工系数和难度系数。
  • 退火/包材重量 = 弯头材料重量 + A/B端直管重量 + A/B端非法兰配件理论重量 + 中接理论重量。
  • 不带法兰：制造管理 = 加工费 x 2.14；带法兰：制造管理 = 扣除法兰后的产品重量 x 4.13。

弯头不含税成本 = 弯头本体配件成本 + A/B端直管材料 + A/B端配件 + 中接配件 + 弯头加工费 + 退火 + 制造管理 + 包材 + 表面处理。
