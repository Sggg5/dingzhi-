# 定制产品出图报价系统

这是一个本地运行的 FRANTA 定制产品出图报价系统，当前覆盖五类产品：

- 分水器类
- 对接类
- 三通类
- 弯头类
- 组合件

系统同时负责参数配置、报价计算、成本拆分、BOM 清单、图纸预览、PNG/PDF/DXF/清单导出、设置数据维护。

## 运行方式

不要用 `file://` 直接打开页面。请通过本地静态服务运行：

```powershell
node server.js
```

然后访问：

```text
http://127.0.0.1:4173/
```

## 主要文件

- `index.html`：页面结构、设置弹窗容器。
- `styles.css`：主界面、侧边栏、设置页、图纸区和成本明细样式。
- `app.js`：页面入口，负责表单联动、报价调用、图纸渲染、导出和事件绑定。
- `quote-core.js`：基础报价公式，包括管材重量、管材成本、配件成本、配件理论重量、加工费查表、配件长度查表和含税/面价换算。
- `product-quote-core.js`：分水器、对接、三通、弯头四类产品的组合报价。
- `cost-detail-core.js`：成本拆分明细，展示表格取值、材质系数、去税换算、加工费取值和最终计入金额。
- `display-core.js`：顶部标题、配置明细、成本行、报价清单展示文本。
- `settings-core.js`：设置数据克隆、合并、导入导出路径和本地保存。
- `dxf-export-core.js`：面向中望/AutoCAD 兼容的 R12 DXF 文件、机械图图层表、文字样式及原生图元序列化。
- `quote-list-storage-core.js`：报价清单草稿的本机序列化、恢复和容量限制。
- `product-draft-storage-core.js`：当前产品参数草稿的本机保存与恢复。
- `quote-history-storage-core.js`：报价版本快照、恢复和本机历史容量限制。
- `settings-render-core.js`：设置页尺寸、配件价格、配件长度、加工费、报价逻辑等表格渲染。
- `drawing-core.js`：图纸共用图框、尺寸线、箭头和内容自适应。
- `manifold-drawing.js`：分水器图纸。
- `docking-drawing.js`：对接类图纸。
- `tee-drawing.js`：三通类图纸。
- `elbow-drawing.js`：弯头类图纸。
- `fitting-drawing.js`、`fitting-renderer.js`、`branch-fitting-renderer.js`：通用配件轮廓和端部/支路配件渲染。
- `tests/`：核心逻辑、图纸、设置、导出、成本明细和烟测。

## 本机数据保护

- 报价清单会在新增、删除、清空和切换价格列时自动保存到本机；重新打开页面后恢复最近 200 项。
- 当前产品参数会按产品类型自动保存为本机草稿；刷新后恢复分水器独立支路、对接中间段、三通中间段、弯头中接和组合件组件。
- 报价清单下方可手动保存当前版本；每个版本包含配置、当时钢价、价格设置版本、清单金额和风险状态，最多保留最近 30 个，可恢复或删除。
- 设置页的“备份全部”会导出 JSON，包含价格设置、当前产品草稿、报价清单、报价历史和设置密码哈希；“恢复备份”会整体覆盖这些本机数据。配件价格表的批量编辑仍建议使用 Excel 导入导出。
- 设置默认密码为 `Franta`。首次成功解锁后，系统只保留本机 SHA-256 密码哈希；可在设置页修改密码，完整备份会保留该哈希。纯本地前端密码用于防止误操作，不替代多用户权限控制。
- 设置页可随时“锁定设置”；锁定后本次会话内再次进入也需要重新验证密码。
- 价格设置读取失败时，系统会先备份原始数据，再恢复默认值；备份键以 `manifoldQuotePricingV1:backup:invalid:` 开头。
- 本机浏览器数据被手工清理或更换电脑后不会自动迁移，请定期导出设置 Excel 和报价清单 CSV。
- 配件价格、配件长度、加工费、重量系数、材质系数或税系数缺失时会标记为报价风险；存在风险的当前配置不能加入报价清单，风险项目也不能导出报价清单。

## 通用报价规则

### 系列和材质

- 系列 A 显示为国标，系列 B 显示为德标。
- 德标系列新增 `15 x 1.5`，作为独立新增规格参与下拉和图纸；不参与国标/德标等价映射，避免影响原有规格切换关系。
- 德标 `15` 暂按德标 `18` 的配件价格、配件长度、三通体长度、弯头中心高和加工费兜底；有专用表后可在设置页替换。
- 304 默认钢价为 `16000 元/吨`。
- 316L 默认钢价按 304 联动，配件材料系数为 `1.6`。
- 管材材料单价按 `不锈钢现价 + 2000` 计算。
- 管材材料成本进入小计前按材料税系数去税，默认 `/ 1.13`。
- 配件价格表维护的是含税价格，进入成本前先去税。
- 316L 配件成本按 `含税表价 x 316L配件系数 / 配件含税系数` 计入。
- 最终工厂成本显示为含税成本。

### 管材重量

默认实际壁厚：

```text
实际壁厚 = 名义壁厚 x 0.9 + 0.02
```

勾选正公差时：

```text
实际壁厚 = 名义壁厚 + 0.05
```

每米重量：

```text
304  每米重量 = 0.02482 x 实际壁厚 x (外径 - 实际壁厚)
316L 每米重量 = 0.02513 x 实际壁厚 x (外径 - 实际壁厚)
```

大规格默认壁厚：

```text
133 = 2.5 mm
159 = 2.5 mm
219 = 3.0 mm
```

### 配件成本透明化

成本拆分里的每个配件会展开显示：

```text
表格取径 Dxx；
含税表价 ¥xx；
去税 ÷ 1.13；
材质系数 x 1.00 或 1.50；
计入成本 ¥xx
```

如果配件没有直接重量，则理论重量按价格反推：

```text
配件理论重量 =
配件去税后成本 / (((固定反推基准钢价 + 2000) / 1000) x 配件重量系数)
```

固定反推基准钢价在设置页维护，默认 16000 元/吨，不跟随当前报价钢价变化。316L 配件价格系数继续参与配件去税成本，不改变现有配件价格规则。配件重量系数按设置表维护，当前包括外丝、内丝、双卡、环压、插焊、法兰、移动螺纹、移动螺母、堵头、中接、沟槽、对焊、45弯头、90弯头。

### 面价

```text
含税工厂成本 = 不含税成本小计 x 含税系数
面价折后 = 含税工厂成本 / 0.68
单件面价 = 含税工厂成本 / 0.68 / 0.17
合计面价 = 单件面价 x 数量 + 运费
```

### 报价清单

- 报价清单支持勾选显示 `成本`、`面价折后`、`面价`。
- 默认只勾选 `面价`。
- 三项可同时勾选，清单会分别显示单价和金额列。
- 清单合计按当前显示的主价格列计算，优先级为：`面价 > 面价折后 > 成本`。
- 导出清单时按当前勾选列输出，保证页面和 CSV 一致。

## 分水器类

### 配置项

- 基础信息：客户、报价编号、材质、管材系列、钢价。
- 主管参数：主管外径、主管壁厚、主管正公差。
- 连接方式：主管进水配件、支管配件、末尾配件。
- 支管参数：支管外径、支管壁厚、支路个数、支路间距、支管加高、支路独立配置。
- 报价参数：数量、表面处理、难度系数、成本率、面价折扣、运费。

### 报价逻辑

- 支路数量支持 `1-20` 口。
- 支路为 `1口` 时，加工费仍按 `2口基础加工费` 起算。
- 主管长度由进水端尺寸、支路间距、支路数量和末尾尺寸计算。
- 支管材料只有在支管加高时计入；不加高时支管管材重量为 0。
- 配件成本包括进水端、末尾端和所有支路配件。
- 支路独立配置可选择 `无配件`，该支路不计配件价格、不画配件、不进入支路配件 BOM；用于双排或上下支路数量不对称。
- 法兰配件计入配件成本，但不进入退火、包材和制造管理重量。
- 分水器退火、包材、制造管理默认按管材总重量计算。

加工费：

```text
加工费基础 = 2口基础加工费 + 增加支路加工 + 加高支路加工
加工费 = (加工费基础 x 规格系数 + 大规格开孔加工) x 难度系数
```

当前规则：

```text
2口基础加工费 = 设置值
每增加1口加工费 = 设置值
每个加高支路加工费 = 设置值
主管外径 <= 50.8：规格系数 x1
主管外径 > 50.8：规格系数 x3
主管为 133/159/219：每个支路孔额外 +15
```

成本小计：

```text
分水器不含税成本 =
主管材料 + 支管材料 + 配件
+ 分水器加工费
+ 退火
+ 制造管理
+ 包材
+ 表面处理
```

### 图纸规则

- 分水器使用统一图框。
- 支管加高超过 `80 mm` 后，图示支管不再继续加长，只影响标注和报价。
- 支管配件为双卡时，图示高度按 `50 mm` 封顶。
- 主管、支管、尺寸线和信息框会在图框内自适应，避免大规格或多支路超框。
- BOM 合并相同项目，支管不加高时不显示支管管材。
- BOM 会跳过 `无配件` 和 `直管` 这类无配件项，避免出现无配件明细行。

## 对接类

### 配置项

- A端：外径、壁厚、连接方式。
- B端：外径、壁厚、连接方式。
- 中间直管：直管外径、直管壁厚、总长要求；总长要求可自动或手动输入，配件长度会参与总长计算。
- A端中间段、B端中间段：各自支持无、直管、中接；选择直管时显示对应直管长度。
- 报价参数：数量、表面处理、难度系数、成型加工系数、成本率、面价折扣、运费。

### 报价逻辑

- A/B端可以不同外径、壁厚和连接方式。
- A/B端配件使用通用配件价格表。
- 对接加工费使用独立的对接类加工费表，不套用分水器、三通或弯头加工费。
- A端/B端中间段为直管时，按对应直管长度、直管外径和直管壁厚计算管材重量和材料费。
- A端/B端中间段为中接时，按中接配件价格计成本，并按对接加工费表计算中接加工。
- A端或B端规格与中间直管规格不一致时，未手动改过的情况下该端自动选择中接；用户选择后不锁死，可以继续修改。
- 法兰只计配件成本，不进入退火、包材和法兰管理重量。

退火/包材重量：

```text
退火/包材重量 =
中间直管重量
+ A/B端非法兰配件理论重量
+ A/B端中接理论重量
```

制造管理：

```text
不带法兰：制造管理 = 加工费 x 2.14
带法兰：制造管理 = 扣除法兰后的产品重量 x 4.13
```

成本小计：

```text
对接不含税成本 =
中间直管材料
+ A/B端配件
+ A/B端中接配件
+ 对接加工费
+ 退火
+ 制造管理
+ 包材
+ 表面处理
```

### 图纸规则

- 对接类使用分水器同款图框。
- A端和B端配件贴合中间连接体。
- A/B端均无中间段且无总长要求时，两端配件直接相连，不显示中间直管。
- 中间直管外径和壁厚显示在管体中心标注。
- 中接按大小头锥度图示，133以上中接图示做短化处理。
- A/B标识放入配件中心；无配件时不显示 A/B 标识。
- 尺寸线贴配件外边缘，规格变化时同步跟随。

## 三通类

### 配置项

- 三通体：外径、壁厚、三通体直管长度。
- A端、B端、C端：外径、壁厚、连接方式。
- A/C端中间段：无或中接。
- B端中间段：无、直管或中接；选择直管时显示直管长度，选择法兰时默认打开 B端直管并带入 `50 mm`，可手动修改。
- 报价参数：数量、表面处理、难度系数、成型加工系数、成本率、面价折扣、运费。

### 报价逻辑

- 三通体长度从国标/德标三通体直管长度表带出，也可手输。
- 三通体选择外径时，默认联动 A/B/C 三端规格。
- A/B/C端配件使用通用配件价格表。
- 三通加工费使用独立三通类加工费表。
- A/B/C端中间段为中接时，计中接配件成本、理论重量和三通中接加工费。
- B端中间段为直管时，按输入长度计管材重量和材料费。
- B端中间段为中接时，计中接配件成本、理论重量和三通中接加工费。
- 133、159、219规格可用沟槽、对焊、法兰。
- 法兰只计配件成本，不进入退火、包材和法兰管理重量。

退火/包材重量：

```text
退火/包材重量 =
三通体直管重量
+ B端直管重量
+ A/B/C端非法兰配件理论重量
+ A/B/C中接理论重量
```

制造管理：

```text
不带法兰：制造管理 = 加工费 x 2.14
带法兰：制造管理 = 扣除法兰后的产品重量 x 4.13
```

成本小计：

```text
三通不含税成本 =
三通体/直管材料
+ A/B/C端配件
+ 中接配件
+ 三通加工费
+ 退火
+ 制造管理
+ 包材
+ 表面处理
```

### 图纸规则

- 三通类使用分水器同款图框。
- 三通体是横向直管，B端配件直接贴在三通体上边线。
- A/C端中接根据变径方向同步旋转。
- B端直管图示和尺寸线根据直管长度缩放，避免超出图框。
- A/B/C标识放入配件中心；配件规格变化时标识跟随。
- 三通体居中显示当前管外径 x 壁厚。
- BOM 显示三通体、A/B/C端配件、中接、B端直管等项目，并合并相同项。

## 弯头类

### 配置项

- 弯头体：外径、壁厚、中心高度 H、角度。
- 角度：支持 `45°` 和 `90°`，不再使用 `180°`。
- A端、B端：外径、壁厚、连接方式。
- A/B端中间段：无、直管、中接；选择直管时显示直管长度输入。
- 报价参数：数量、表面处理、难度系数、成型加工系数、成本率、面价折扣、运费。

### 报价逻辑

- 弯头本体价格使用配件价格表里的 `45弯头` 或 `90弯头` 行。
- 弯头本体价格表为含税价，进入成本前去税，并按材质系数处理。
- 弯头材料重量用于退火、包材和表面处理，不直接决定弯头本体价格。
- 弯头材料重量按中心高度 H 的规则折算，当前料长逻辑为 `H x 2.5`。
- 45度弯头长度/高度相关取值按 90度规则乘角度系数，当前 45度角度系数为 `0.8`。
- A/B端配件使用通用配件价格表。
- A/B端中间段为直管时，按输入长度计管材重量和材料费。
- A/B端中间段为中接时，按中接配件价格和弯头加工费表计算。
- 弯头加工费使用独立弯头类加工费表。
- 法兰只计配件成本，不进入退火、包材和法兰管理重量。

退火/包材重量：

```text
退火/包材重量 =
弯头本体材料重量
+ A/B端直管重量
+ A/B端非法兰配件理论重量
+ 中接理论重量
```

制造管理：

```text
不带法兰：制造管理 = 加工费 x 2.14
带法兰：制造管理 = 扣除法兰后的产品重量 x 4.13
```

成本小计：

```text
弯头不含税成本 =
弯头本体配件成本
+ A/B端直管材料
+ A/B端配件
+ 中接配件
+ 弯头加工费
+ 退火
+ 制造管理
+ 包材
+ 表面处理
```

### 图纸规则

- 弯头类使用分水器同款图框。
- 弯头体两边为实线，中间为中心线。
- 90度尺寸标注分为 A端到弯头中心、B端到弯头中心。
- 45度尺寸标注分为 A端水平中心高度、B端沿斜管方向中心高度。
- A/B端尺寸界限贴配件边缘，并随规格和配件长度变化。
- A/B端标识放在配件中心，字体与其它标注一致。
- 大规格或长直管会在图框内自适应缩放，避免超出图框。

## 组合件

### 配置项

- 基础信息：客户、报价编号、材质、管材系列、钢价。
- 端部配件：A端配件、B端配件。
- 主链组件：按 A端到 B端顺序添加直管、45度弯头、90度弯头、三通。
- 直管组件：外径、壁厚、长度。
- 弯头组件：外径、壁厚、中心高、转向方向。
- 三通组件：主管外径、壁厚、主管长度、支口外径、支口壁厚、支口长度、支口末端配件、中间段。
- 三通支口组件：支口后可继续添加直管、45度弯头、90度弯头。

### 报价逻辑

- 当组合件只有一个组件时：
  - 直管按对接类规则计价。
  - 三通按三通类规则计价。
  - 弯头按弯头类规则计价。
- 多组件组合件按组件序列累计：
  - 直管、三通主管、三通支管、支口直管按管材重量计算材料费。
  - 弯头本体按配件价格表中的 `45弯头` 或 `90弯头` 取含税表价，进入成本前去税并乘材质系数。
  - 弯头组件和三通支口弯头同时按 `中心高 H x 2.5` 折算本体材料重量，用于管材材料、退火、包材和表面处理明细。
  - A/B端配件、三通支口配件、中接按通用配件价格表取值。
  - 主链相邻组件之间按焊接点计入加工费，调用弯头类加工费表的 `对焊` 行，外径取相邻两段较大值。
  - 如果 `对焊` 行暂无取值，暂按弯头类加工费表的 `双卡` 行兜底。
  - 三通体基础加工费、支口每段组件加工费、组合件制造管理加工系数在组合件设置中独立维护。
- 退火和包材重量按管材重量 + 非法兰配件理论重量估算。
- 表面处理只按实际管材重量计算，不按配件理论重量计算。

成本小计：

```text
组合件不含税成本 =
管材材料
+ 端部/弯头/支口配件
+ 组合加工
+ 退火
+ 制造管理
+ 包材
+ 表面处理
```

### 图纸规则

- 组合件使用分水器同款图框。
- 主链按组件顺序绘制，直管显示直线中心线，弯头使用圆弧中心线，三通支口可继续接直管或弯头。
- 每段直管标注 `L`，弯头使用引出线标注 `H`。
- 组合件成本拆分会展开主链直管、三通主管/支管、主链弯头本体材料、支口弯头本体材料、端部配件、支口配件和焊接点加工。
- 总长包含 A端、B端及支口配件的外形占位。
- A端、B端和支口末端配件应显示配件标识；无配件时不显示。
- 隐藏说明区后，图示和总尺寸线仍应保持在图框有效区域内。

## 设置页面

设置页按产品类别分为：

- 分水器类
- 对接类
- 三通类
- 弯头类
- 组合件

每类内部按设置类型分为：

- 尺寸
- 配件价格
- 配件长度
- 加工费
- 报价逻辑

说明：

- 分水器、对接、三通、弯头、组合件的加工费独立维护。
- 对接、三通、弯头共用通用配件价格和通用配件长度。
- 组合件调用通用配件价格、通用配件长度、弯头配件价格，并使用独立组合加工设置。
- 插焊目前仅对对接、三通、弯头开放；价格和长度默认按环压 `x 0.75`。
- 设置数据保存到本地浏览器，下次打开优先读取本地保存值。
- 设置可恢复默认。
- 设置数据支持导出/导入，方便批量修改。
- 设置密码可在设置页修改，长度为 6 至 128 位；恢复默认价格不会重置密码。

## 图纸和 BOM

- 五类产品共用同一张工业图框。
- 图纸中的配件轮廓、尺寸线、端部标识会随规格、配件类型和直管长度变化。
- 尺寸线只标产品关键尺寸，图框信息区显示尺寸说明、技术参数和 BOM。
- 尺寸线支持手动拖动微调，但只允许按制图方向偏移：水平尺寸线上下移动，竖向尺寸线左右移动，45度和组合件斜向尺寸线沿法向移动。
- 切换产品、新建报价、组合件增删或移动组件时，会清空旧尺寸线偏移，避免上一张图纸的人工微调影响新图纸。
- BOM 按当前产品配置生成，相同项自动合并数量。
- 对接、三通、弯头图纸标题和图框规格不写材质、不写无关壁厚，端部规格按连接方式显示。

## 导出

- 导出 PNG：保存当前 SVG 图纸为 PNG。
- 导出 PDF：打开仅包含图纸的打印页，可选择浏览器 PDF 或系统 PDF 打印机。
- 导出 DXF：输出兼容性优先的 R12 ASCII DXF，单位为毫米，A3 横向图框映射为毫米坐标；包含中望机械版可用的 `CENTER2`、`DASHED2`、`PHANTOM4` 线型、文字样式、图层与 `BLOCKS` 节。文字样式使用本机中望机械版自带的 `txt.shx + GBCBIG.SHX`；中文使用 AutoCAD `\\U+XXXX` Unicode 转义，避免旧 CAD 将 UTF-8 读为问号。图层按机械制图用途建立：`01_OUTLINE` 轮廓实线、`02_THIN` 细线、`03_CENTER` 红色 `CENTER2` 中心线、`04_HIDDEN` 洋红 `DASHED2` 虚线、`05_HATCH` 剖面、`06_TEXT` 绿色文字、`07_DIMENSION` 天蓝色标注、`08_SYMBOL` 符号、`09_PHANTOM` 双点划线、`10_OUTLINE_HIDDEN` 轮廓虚线、`11_SECTION` 剖图、`12_FRAME` 图框、`13_NO_PLOT` 消隐。圆形符号导出为原生 `CIRCLE`，由直线和圆弧构成的弯头轮廓、中心线导出为原生 `LINE + ARC`；无法无损转换的复杂 SVG 曲线才降级为传统 `POLYLINE/VERTEX`，便于在 AutoCAD、中望、浩辰等软件中继续编辑。
- 导出清单：导出报价清单数据，价格列按当前清单勾选项输出。
- 设置导出/导入：用于价格、长度、加工费等基础表批量维护。

## 开发边界

- `*-core.js` 尽量不依赖 DOM。
- 报价计算必须使用产品配置中的 `tubeSeries`，不能偷读当前页面选项。
- 四类产品的加工费、图纸逻辑、配置逻辑要分开，不要混用。
- 成本明细只展示计算过程，不应重复计算核心报价。
- 图纸渲染只读取产品配置和报价结果，不直接修改报价状态。
