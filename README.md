# 定制产品出图报价系统原型

这是一个本地运行的定制产品出图报价原型，已包含：

- 一级产品入口：分水器类、对接类、弯头类、三通类
- 分水器配置规则联动
- 对接、弯头、三通的基础参数、示意图和估算报价
- 对接类支持 A/B 两端不同规格和不同连接方式
- 三通类支持三通体、A/B/C 三端配件和中间段配置
- 弯头类支持 45°、90° 弯头体、A/B 端配件和中间段配置
- 支管外径自动过滤
- 支路间距可手动输入，并提供常用值提示
- 主管壁厚默认派生和手动覆盖
- 支管壁厚自动同步
- 支路默认统一配置，也可切换为每一路独立配置
- 报价计算
- 简易图纸预览
- 打印报价单

## 打开方式

建议通过本地静态服务运行，不使用 `file://` 直接打开页面。

在项目目录中启动服务后访问：

```text
http://127.0.0.1:4173/
```

- `styles.css`：页面、侧边栏和图纸预览样式。

## 报价模型

当前报价采用可调整的内部估算模型。四类产品共用基础价格表、材质倍率、税率和面价规则，但管材重量、加工费、退火重量和包材重量的取法不同。

### 通用规则

- 系列 A 显示为 `国标`，系列 B 显示为 `德标`。
- 304 不锈钢现价默认 `16000 元/吨`。
- 316L 不锈钢现价按 304 的 `1.65` 倍，默认 `26400 元/吨`。
- 管材材料价格统一按 `当前不锈钢现价 + 2000` 计算。
- 管材材料费按 `/ 1.13` 去税。
- 配件价格表按含税价格维护；进入成本小计前会先按含税系数去税，316L 配件价格按 304 价格的 `1.5` 倍计算后再去税。
- 各项成本先形成不含税小计，最后统一乘含税系数，默认含税系数为 `1.13`。
- 默认实际壁厚：`名义壁厚 x 0.9 + 0.02`。
- 国标大规格默认壁厚：`133 = 2.5 mm`，`159 = 2.5 mm`，`219 = 3.0 mm`。
- 勾选正公差时，计算重量使用：`名义壁厚 + 0.05`。
- 304 每米重量：`0.02482 x 实际壁厚 x (外径 - 实际壁厚)`。
- 316L 每米重量：`0.02513 x 实际壁厚 x (外径 - 实际壁厚)`。
- 配件没有直接重量时，按重量系数折算理论重量：

```text
配件理论重量 = 配件去税后成本 / ((不锈钢现价 + 2000) / 1000 x 重量系数)
```

- 面价采用“面价 17 折”方式：

```text
含税工厂成本 = 不含税成本小计 x 1.13
面价折后 = 含税工厂成本 / 0.68
单价面价 = 含税工厂成本 / 0.68 / 0.17
合计面价 = 单价面价 x 数量 + 运费
```

### 分水器类报价逻辑

- 分水器由主管、支管、进水端配件、末尾配件和各支路配件组成。
- 支路数量支持 `1-20` 口；当支路为 `1口` 时，加工费仍按 `2口基础加工费` 起算。
- 主管长度按进水尺寸、支路间距、支路数量和末尾尺寸计算；支路间距可统一输入，也可在支路独立配置中逐段输入。
- 主管材料重量：`主管每米重量 x 主管长度 / 1000`。
- 支管只有在加高时计算材料重量；支管不加高时，支管材料重量和支管材料费均为 `0`。
- 支管材料重量：`支管每米重量 x 支管加高长度 / 1000`。
- 图纸预览中，支管加高超过 `80 mm` 后不再继续拉长图示；支管配件为双卡时，图示按 `50 mm` 高度封顶。该限制只影响图示，不影响报价重量和标注数值。
- 配件成本包括主管进水配件、主管末尾配件和所有支管配件。
- 加工费使用分水器类设置项：

```text
2口基础加工费 = 6.82
每增加1口 = +1.81
每个加高支路 = +1
主管外径 <= 50.8：规格倍率 x1
主管外径 > 50.8：规格倍率 x3
主管外径为 133/159/219：每个支路孔额外 +15
```

- 分水器难度系数默认自动计算：不同支口规格、配件、加高、正公差会增加难度；双排分水器和存在支管加高也会增加难度。手动填写难度系数时，以手动值为准。
- 分水器的退火、制造管理、包材和表面处理都按管材总重量计算，主管、尾端和支路上的法兰只计配件成本，不进入退火重量、包材重量和制造管理重量：

```text
退火费 = 管材总重量 x 1.2
制造管理费 = 管材总重量 x 4.13
包材成本 = 管材总重量 x 0.938
酸洗 = 0 元/kg
喷砂 = 管材总重量 x 1
抛光 = 管材总重量 x 1
```

- 分水器不含税成本小计：

```text
分水器不含税成本 =
主管材料费
+ 支管材料费
+ 配件成本
+ 分水器加工费
+ 退火费
+ 制造管理费
+ 包材成本
+ 表面处理费
```

顶部显示的分水器工厂成本为 `分水器不含税成本 x 1.13`。

### 对接类报价逻辑

- A 端和 B 端分别选择外径、壁厚和连接方式，可以两端不同规格。
- A/B 端配件费用复用通用配件含税价格表；304 先去税入成本，316L 按 `含税价 x 1.5` 后再去税入成本。
- 对接类加工费使用独立的 `对接类加工费` 表，按 `配件类型 x 外径` 取值，不使用分水器、三通或弯头加工费。
- 中间段为直管时，按中间直管长度计算管材重量和材料费；中间段为中接时，按中接配件价格计算配件成本，并按对接类加工费表计算中接加工费。
- 配件没有直接重量时，按 `配件理论重量 = 配件去税后成本 / ((不锈钢现价 + 2000) / 1000 x 重量系数)` 估算。
- 对接退火重量和包材重量使用 `中间直管重量 + A/B端非法兰配件理论重量 + 中接理论重量`；A/B 端选择法兰时，法兰只计配件成本和配件理论重量展示，不参与退火和包材。
- 表面处理只按直管材料重量计算，不按配件理论重量计算。
- 不带法兰时，制造管理费按 `加工费 x 2.14` 计算；带法兰时，制造管理费按 `扣除法兰后的产品重量 x 4.13` 计算。
- 自动难度系数：基础为 `1`；A/B 端外径或壁厚不同 `+0.08`；有中接 `+0.05`；多段中间段超过 1 段后每段 `+0.02`。手动填写难度系数时，以手动值为准。
- 对接不含税成本小计：

```text
对接不含税成本 =
中间直管材料费
+ A/B端配件成本
+ 中接配件成本
+ 对接加工费
+ 退火费
+ 制造管理费
+ 包材成本
+ 表面处理费
```

顶部显示的对接工厂成本为 `对接不含税成本 x 1.13`。

### 三通类报价逻辑

- 三通体由三通体外径、壁厚和三通体直管长度决定，三通体直管长度可从国标/德标表带出，也可手动输入。
- A/B/C 三端分别选择外径、壁厚和连接方式，三端配件费用复用通用配件含税价格表，进入成本小计前先去税。
- 三通类加工费使用独立的 `三通类加工费` 表，按 `配件类型 x 外径` 取值。
- A 端和 C 端中间段支持 `无` 或 `中接`；选择中接时计算中接配件成本、配件理论重量和三通类中接加工费。
- B 端中间段支持 `无` 或 `直管`；选择直管时按 B 端直管长度计算管材重量和材料费。B 端选择法兰时，系统会默认打开 B 端直管并带入长度 `50 mm`，仍可手动修改。
- 配件理论重量按重量系数估算；法兰只计配件成本和配件理论重量展示，不参与退火和包材；表面处理只按三通体直管和 B 端直管等实际管材重量计算。
- 三通退火重量和包材重量使用 `三通体直管重量 + B端直管重量 + A/B/C端非法兰配件理论重量 + 中接理论重量`。
- 不带法兰时，制造管理费按 `加工费 x 2.14` 计算；带法兰时，制造管理费按 `扣除法兰后的产品重量 x 4.13` 计算。
- 自动难度系数：基础为 `1.12`；A/C 有中接 `+0.05`；A/B/C 中间段超过 1 个后每个 `+0.02`。手动填写难度系数时，以手动值为准。
- 三通不含税成本小计：

```text
三通不含税成本 =
三通体/直管材料费
+ A/B/C端配件成本
+ 中接配件成本
+ 三通加工费
+ 退火费
+ 制造管理费
+ 包材成本
+ 表面处理费
```

顶部显示的三通工厂成本为 `三通不含税成本 x 1.13`。

### 弯头类报价逻辑

- 弯头体由弯头体外径、壁厚、中心高度 H 和角度决定；角度支持 `45°`、`90°`。
- 弯头本体成本使用配件含税价格表中的 `45弯头` 或 `90弯头` 价格，进入成本小计前先去税，不按弯头本体理论重量计入本体价格。
- 弯头材料重量按 `中心高度 H x 2.5` 的料长计算，用于表面处理和成本明细中的料长重量展示。
- A/B 端分别选择外径、壁厚和连接方式，A/B 端配件费用复用通用配件含税价格表，进入成本小计前先去税。
- A/B 端中间段支持 `无`、`直管`、`中接`；直管按输入长度计算管材重量和材料费，中接按中接配件价格和弯头类加工费表计算。
- 弯头类加工费使用独立的 `弯头类加工费` 表，按 `配件类型 x 外径` 取值；弯头法兰加工费按弯头类表单独维护。
- 弯头加工费会乘角度系数：`90° = 1`，`45° = 0.8`，再乘成型加工系数和难度系数。
- 自动难度系数：基础为 `1.08`；有中接时 `+0.05`。手动填写难度系数时，以手动值为准。
- 退火和包材重量不使用弯头本体理论重量，而使用 `弯头材料重量 + A/B端直管重量 + A/B端非法兰配件理论重量 + 中接理论重量`；A/B 端选择法兰时，法兰只计配件成本和配件理论重量展示，不参与退火和包材。
- 表面处理按 `弯头材料重量 + A/B端直管重量` 计算，不按配件理论重量计算。
- 不带法兰时，制造管理费按 `加工费 x 2.14` 计算；带法兰时，制造管理费按 `扣除法兰后的产品重量 x 4.13` 计算。
- 弯头不含税成本小计：

```text
弯头不含税成本 =
弯头本体配件成本
+ A/B端直管材料费
+ A/B端配件成本
+ 中接配件成本
+ 弯头加工费
+ 退火费
+ 制造管理费
+ 包材成本
+ 表面处理费
```

顶部显示的弯头工厂成本为 `弯头不含税成本 x 1.13`。

### 图纸和 BOM

- 四类产品共用同一图框样式，按当前参数自动重绘 SVG 图纸。
- 图纸尺寸标注会根据产品类型显示总长、中心高、展开长或中间段尺寸。
- BOM 会按当前产品类型列出管材、弯头体、三通体、A/B/C 端配件、中间段直管和中接等项目。
- 相同 BOM 项目会自动合并数量。
- 分水器支管不加高时，BOM 不体现支管管材，只体现支管配件。
- 双排分水器由上排镜像生成，下排尺寸线和信息框会自动下移。

真实投产前建议把 `app.js` 中的 `pricing` 改成企业实际价格表，或接入数据库。

## 价格设置保存

- 点击顶部 `设置` 需要输入密码 `Franta`。
- 设置页按 `分水器类`、`对接类`、`三通类`、`弯头类` 分开维护。
- 通用配件价格和配件长度可被对接、三通、弯头共用。
- 对接类、三通类、弯头类加工费各自独立，不互相套用。
- 修改价格设置后，先在当前页面即时生效。
- 点击 `保存价格` 后写入本机浏览器，下次打开会优先调用已保存价格。
- 点击 `恢复默认` 后，会恢复系统默认价格，并把默认价格重新保存到本机。
